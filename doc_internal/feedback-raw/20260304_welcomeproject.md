# Feedback: Arrival Resources Web App
**Organization:** The Welcome Project  
**Role:** Social Worker (ESOL director)
**Date:** 2026-03-04  

## Positive Feedback

- Visual design helpful (service tags, color coding)
- Map + list view useful
- Search by organization name helpful
- Print function useful for referrals
- Fits social worker workflow (they maintain their own informal list)

## Context Shared

- Their summer intern built a community resource hub using Google Sites:
  https://sites.google.com/welcomeproject.org/twpcommunityresources/home

- Site organizes resources by city (Somerville, Medford, Malden, Everett)
- Categories include family support, unemployment, career, immigration, schools, health.

This suggests an existing demand for a curated resource hub.

## Observations from Staff

- Many newcomers rely on **face-to-face referrals** rather than searching online.
- Trust and personal networks play a large role in where people go for services.
- Social workers often refer clients to organizations where they know someone personally.

## Suggested Improvements

1. **Language support**
   - Key barrier for direct newcomer use.

2. **Digital divide**
   - Some users may not access digital resources easily.

3. **More comprehensive listings**
   - A larger database of organizations would improve usefulness.

4. **Trust / relationship layer**
   - Referrals often depend on known contacts and organizational reputation.

## Data Corrections

- Remove **Financial Literacy** service tag from **The Welcome Project**.

## Potential Contribution

- Staff offered to share a list of ~10 organizations they regularly refer clients to when this project develops further.
